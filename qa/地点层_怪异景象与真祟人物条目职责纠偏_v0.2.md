## 一、纠偏结论

上一版将《夜班交接表》《缺席名单》《四栋零单元》《回门牌》直接称为“固定真祟隐藏主线骨架”，职责过界。

用户确认：这四者更准确的定位是**固定怪异景象 / 深层异常征兆**，不是真祟本体。

因此自本版起：

- SITE 地点条目负责正常功能、人群生态、表层传闻、随机梗小鬼土壤、固定怪异景象、调查线索、现象规律、临时处置目标、不可逆余波与城市级遗痕；
- 真祟本体必须在后续人物生产阶段，以独立人物条目生成；
- 真祟人物条目负责外貌、人格、存在根源、历史、能力、恐怖意象、行为逻辑、与地点及怪异景象的真实关系；
- 地点条目不得提前代写真祟完整本体，也不得把怪异景象本身等同于真祟。

结果：PASS。

## 二、固定真祟主线硬规则的保留方式

“每个正式核心地点至少预设一条固定真祟隐藏主线”继续有效，但施工拆成两层：

1. 地点阶段：建立固定怪异景象，并预留唯一 `true_haunting_ref`；
2. 真祟人物阶段：生成该地点真正的固定真祟人物条目，并回填引用。

随机梗小鬼、直播挑战、网络谣言和普通怪谈只能成为表层事件，绝不能占用或替换 `true_haunting_ref`。

结果：PASS。

## 三、南城第一批重新定性

- SITE_NC01：《夜班交接表》＝医疗记录 / 空间 / 身份误归类的固定怪异景象；真祟本体待人物条目。
- SITE_NC02：《缺席名单》＝身份 / 集体记忆消退的固定怪异景象；真祟本体待人物条目。
- SITE_NC03：《四栋零单元》＝家庭关系 / 居住归属替换的固定怪异景象；真祟本体待人物条目。
- SITE_NC04：《回门牌》＝地址 / 空间对应失效的固定怪异景象；真祟本体待人物条目。

四个景象均可由未来真祟造成、利用、伴生或放大，但目前不锁死具体关系，避免地点阶段越权决定人物阶段答案。

结果：PASS。

## 四、后续地点生产硬规则

从下一批地点起统一使用：

**正常功能 → 人群生态 → 表层传闻 / 随机异常土壤 → 固定怪异景象 → 调查线索与已知规律 → 真祟人物条目预留接口 → 城市级遗痕。**

不再在 SITE 文件中直接完整生成真祟。
