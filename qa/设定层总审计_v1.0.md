## 一、核心因果一致性检查

### 1. 梗小鬼 / 模因 / 真祟

PASS。

- 梗小鬼：先有模因、共同识别与传播，再可能异常映现。
- 真祟：不依赖集体相信、传播与模因才存在。
- 人为事件可以制造或催生真祟，但这不等于“很多人相信就能制造真祟”。
- 关于真祟的传闻可以成为模因，甚至进一步映现梗小鬼；真祟本体、传闻模因、模因映现个体必须分开。

### 2. 收容 / 击散 / 复现

PASS。

- 击散只处理当前现身，不等于永久消灭。
- 收容是把当前异常状态变成可管理状态，不要求抹除原梗。
- 原个体脱离收容、同源复现、收容条件失效三者已经明确区分。
- 再次映现不默认原个体复活，也不默认继承原人格、记忆与关系。

### 3. 传播规模 / 危险 / 战斗力

PASS。

- 等效点赞只描述传播规模。
- 传播更广可以提高复现与扩散风险，但不自动提高战斗力、恶意或危险等级。
- 直播、平台算法与造梗可以改变传播环境，但都不是直接的“战力强化器”。

### 4. 法脉 / 法力 / 大恐怖

PASS。

- 法脉是长期积累的灵异处置经验，不是统一法力体系。
- 不存在通用法力值、修仙境界、职业克制表或统一能量等级。
- 仪轨与法器可以在特定条件下真实有效，但施行者仍是会受伤、疲劳、恐惧和死亡的人。
- 法脉增加的是方法、经验与生存机会，不取消真祟造成的力量不对等与未知。

### 5. 未知 / 规则 / 叙事公平

PASS。

- 真祟规律可以不完整、旧经验可以失效。
- 失效必须存在可调查、可回溯的案件内原因。
- 不允许为了惊吓或杀角色临时改规则。
- “无法理解全部本质”不等于“任何调查都没有意义”。
