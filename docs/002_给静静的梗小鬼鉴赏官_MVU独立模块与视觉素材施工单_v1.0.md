# 4. Page 01｜今日鉴赏：老虎机

这是本卡 MVU 第一核心功能。

## 4.1 数据池

正式数据源：

`mvu/src/pools/slot-pools.v0.1.json`

已经封版：

- 外貌池：72 条；
- 点赞池：7 档；
- 梗池：226 条；
- 基础组合：113,904 种。

不得擅自重写池子。

不得把池中词条提前扩写成完整角色。

老虎机只抽取三个种子：

1. 外貌特征；
2. 等效点赞等级；
3. 梗词条。

抽取结果是正文 AI 的生成约束，不是完整梗小鬼角色卡。

## 4.2 等效点赞权重

读取现有 pool 权重：

- 百赞级 30%；
- 千赞级 25%；
- 万赞级 20%；
- 十万赞级 12%；
- 百万赞级 7%；
- 千万赞级 4%；
- 全网级 2%。

不得改成等概率。

不得把点赞等级做成 SSR/UR 稀有度或战力。

## 4.3 每日一次机制

**这里不是新机制设计任务。**

直接复用咩咩制卡包·全栈 / 既有成熟项目中已经验证过的：

- 每自然日仅可抽取一次；
- 当日结果锁定；
- 页面刷新不得重抽；
- 重新打开聊天不得重抽；
- 跨自然日自动解锁；
- 新日期再次允许抽取。

禁止重新发明第二套日期状态机。

禁止使用依赖不稳定楼层文本的“伪每日锁”。

需要使用既有成熟状态变量 / local state / MVU runtime 方案时，按全栈真实实现复用。

## 4.4 动画

三列老虎机：

- 外貌；
- 传播等级；
- 梗。

点击 `开始鉴赏`：

三列滚动并依次停止。

推荐停止顺序：

外貌 → 传播等级 → 梗。

动画必须轻量。

Android / SillyTavern 流畅优先。

不需要 WebGL、Canvas 重特效或大型粒子系统。

当日已抽取后按钮显示：

`今日已鉴赏`

并不可再次正式抽取。

## 4.5 抽取结果对正文的交付

最终结果应能够被正文 AI 可靠读取，例如形成稳定的状态/事实：

- 今日外貌种子；
- 今日点赞等级；
- 今日梗词条；
- 今日抽取日期；
- 今日已抽取标记。

具体字段名必须服从咩咩全栈成熟 MVU/状态格式。

不得为了实现这个功能修改世界书业务正文。

本页不用真地图，不做 3D。

- 西北山麓—水库带；

- 东南近郊—乡镇农业带。

推荐显示名：

- 南城线；
- 北岸线；
- 学城线；
- 工业线；
- 山麓线；
- 沿江线；
- 东南支线。

## 5.2 站点

读取现有地点事实源与：

`manifest/worldbook-locations.v1.1.json`

将现有 42 个核心地点映射为线路站点。

静静只负责把现有地点做成 UI 站点，禁止新增第43个核心地点，禁止改名，禁止重写地点业务正文。

点击站点时显示：

- 地点名；
- 所属区域；
- 极短说明；
- `前往` 按钮。

## 5.3 前往行为

`前往` 只负责将玩家明确意图送入正文输入/交互桥。

例如：

`{{user}}决定前往南城老城区·某地点。`

优先复用咩咩全栈已有的输入框填字桥 / prompt 注入方式。

不得由 MVU：

- 自动推进剧情；
- 自动跳时间；
- 自动生成案件；
- 自动生成 NPC；
- 自动触发固定真祟；
- 自动决定抵达结果。

地图只负责导航。

## 5.4 技术限制

使用 DOM / SVG / CSS 等轻量方式。

不得引入 3D 引擎。

不得依赖真实 GPS / 地理坐标。

必须兼容 Android SillyTavern。

# 6. Page 03｜异模办：16人好感度与秘密

固定展示：

- 10 名鉴赏官；
- 6 名普通工作人员。

现有正式人物事实源位于：

- `worldbook/characters/appraisers/`
- `worldbook/characters/other/STAFF01～STAFF06`
- `manifest/worldbook-appraisers.v0.1.json`
- `manifest/worldbook-staff.v0.1.json`

静静不得修改人物设定。

## 6.1 好感度读取

**这里同样不是新技术设计任务。**

直接复用咩咩预设已经存在、且在既有项目中成熟可用的角色好感度机制。

必须：

- 先读取最新版咩咩预设真实好感度数据结构；
- 直接只读现有好感度；
- UI展示当前值与进度条；
- 不创建第二套 affection/favor/favourability 变量；
- 不做双向同步；
- 不覆盖咩咩状态；
- 不因 MVU 重载重置好感度。

数据流必须是：

`咩咩已有好感度 → MVU只读展示`

## 6.2 50点秘密

规则：

- 当前好感度 < 50：显示锁定；
- 当前好感度 ≥ 50：解锁该角色个人秘密；
- 解锁后永久保持已解锁，不因好感度之后下降再次锁回。

每人只做 1 个秘密。

v1.0 不做多级羁绊树。

个人秘密内容必须从现有人物性格与设定延伸，不能推翻人物档案。

可以是：

- 小癖好；
- 黑历史；
- 隐藏收藏；
- 羞耻网名；
- 生活弱点；
- 私人反差；
- 小段过去。

不要16个人全部写成沉重创伤。

本作整体仍然是“搞笑都市灵异 + 隐藏大恐怖”。
